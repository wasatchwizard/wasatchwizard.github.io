# Site fonts

Merriweather headings and Oxygen body text match the existing public
wasatchwizard.com site. These Latin WOFF2 files are served locally, with
`font-display: swap` and normal system-font fallbacks.

The source URLs and requested styles are recorded in `sources.json`. The
upstream licenses are included alongside the files. Font files are checked in;
building or reading the site does not contact Google Fonts.
