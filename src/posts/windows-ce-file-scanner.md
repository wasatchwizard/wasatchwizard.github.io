I created a utility a while back for getting specific file details that LDHM doesn't already get. Someone asked for it on the LANDesk forums, so I took my lunch hour today and made it available on my web-site.  
  
When run on a Windows CE-based device, it will scan specified folders and/or files and output the information to an LDMS-based BNF file (plain-text). It contains no user-interface, but works very nicely. Check it out  
  
[http://www.wasatchwizard.com/downloads/ScanFiles.aspx](https://web.archive.org/web/*/http://www.wasatchwizard.com/downloads/ScanFiles.aspx)
